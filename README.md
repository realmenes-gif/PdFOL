# PdFOL

Visor de PDF para Windows que **aplana** planos pesados, **folia** y **comprime**, además de organizar, unir,
buscar, resaltar, comparar e imprimir. Hecho en Python (PyMuPDF, pikepdf, CustomTkinter).

## Descargar
En **Releases**: `PdFOL_instalador.exe` (instalable, sin administrador) o `PdFOL_portable.zip` (portable).

## Armar a mano
Descomprimí el código y ejecutá `crear_portable.bat` en Windows (crea el portable y el instalador).
Ver `LEEME.txt`.
